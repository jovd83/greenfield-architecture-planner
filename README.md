`greenfield-architecture-planner` plans architecture for a new software project before repository bootstrap or implementation.

## What It Produces

- Architecture plan
- Stack recommendation
- System boundaries
- Conceptual data model
- API and integration contract outline
- UI architecture notes
- Security and privacy considerations
- Deployment and local development shape
- Validation strategy
- Decision log

## Usage

```text
Use $greenfield-architecture-planner to plan the architecture for this new marketplace app after the user stories and acceptance criteria are drafted.
```
